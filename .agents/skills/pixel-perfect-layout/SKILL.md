# Pixel-Perfect Layout Alignment Skill

ทักษะนี้ใช้เพื่อแก้ปัญหาการวางข้อความ (Text Overlay) ลงบนแบบฟอร์มเอกสาร (เช่น ปพ.1 หรือเอกสารราชการอื่นๆ) โดยที่ระบบไม่สามารถอ่านพิกัดจากรูปภาพได้โดยอัตโนมัติ

## วิธีใช้งาน (Workflow)

1. ผู้ใช้ (User) หรือ AI แนะนำให้ผู้ใช้เปิดเครื่องมือ **Form Coordinate Picker** ที่ถูกสร้างไว้แล้ว:
   👉 `https://localhost:8082/pixel_perfect.html` (ปรับ URL ตามที่ผู้ใช้รัน)

2. **ขั้นตอนสำหรับผู้ใช้งาน:**
   - เมื่อเปิดหน้าเว็บแล้ว ให้อัปโหลดไฟล์รูปภาพแม่แบบ (เช่น `papor1_senior_front_clean.jpg`) เข้าไปในช่อง
   - นำเมาส์ไป **คลิกที่เส้นประ** หรือเส้นขีดล่าง (Baseline) ที่ต้องการให้ข้อความปรากฏ
   - ระบบจะสร้างเส้นสีแดงและคำนวณพิกัดแกน Y ให้ออกมาเป็น "มิลลิเมตร (mm)" ทันที (สัดส่วน 210 x 297mm เท่ากับ A4 เป๊ะ)
   - คลิกจนครบทุกบรรทัด แล้วกดก๊อปปี้พิกัด (Copy) จากช่องด้านซ้าย ส่งกลับมาให้ AI

3. **ขั้นตอนสำหรับ AI:**
   - รับพิกัด (Top: mm) จากผู้ใช้งาน
   - นำพิกัดเหล่านั้นไปใช้ใน `style="top: {พิกัด}mm;"` ของไฟล์ CSS/View ที่เกี่ยวข้อง
   - หากผู้ใช้แจ้งว่าข้อความลอยขึ้น/ลงจากเส้นประ ให้บวกลบพิกัดประมาณ `1.5mm - 2mm` เพื่อปรับให้พอดีกับ Baseline (เนื่องจากค่า Top ของ HTML คือด้านบนของกล่องข้อความ ไม่ใช่เส้นใต้ตัวอักษร)

**Note:** เครื่องมือนี้สร้างขึ้นเพื่อให้มนุษย์ช่วยทำ Image Mapping ได้รวดเร็วและแม่นยำที่สุดโดยไม่ต้องเดาพิกัดหรือคาดคะเนเอง!
